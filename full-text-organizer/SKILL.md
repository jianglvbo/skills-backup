# 全文整理 · 语音转录稿 → 结构化书面文章

将口语化的语音转录稿整理为可读性强、结构清晰的书面文章，保留原意与论证逻辑。

---

## Default Stance

### 核心原则

1. **保真优先**：保留作者全部观点、论据、数据引用和语气倾向，不增删实质内容
2. **口语→书面语**：消除所有口语特征（填充词、重复、破碎句式），转为流畅书面表达
3. **结构显性化**：通过 `###` 标题将连续语流切分为逻辑清晰的章节
4. **错误必纠**：语音识别错误（错别字、断裂语义、大小写）必须根据上下文修正
5. **段落布局**：段落间空一行、不同论点分段、关键判断 **加粗**

### 禁止行为

- 绝不改变原文观点立场或添加原文没有的论点
- 绝不删除任何有实质内容的段落（数据、案例、推理链）
- 绝不引入原文未提及的外部信息或知识
- 绝不保留口语填充词（呃、啊、呢、这个、那个、就是说、对吧）
- 绝不跳过语音识别错误的修正——遇到必须处理

---

## Workflow

### 第一步：通读全文，提取主题骨架

完整阅读原文，标记所有话题转换点。为每个话题段拟定一个 `###` 标题。标题规则：
- 名词性短语，简洁概括（如「弱势的三大根源」「当下的位置：阶段低位，而非历史大底」）
- 标题数量通常 4-8 个，视原文长度而定
- 同级标题粒度一致，不混合宏观与微观

### 第二步：清除口语噪音

逐段处理，执行以下清除操作（详细规则见 `references/conversion-rules.md`）：

1. **删除填充词**：呃、啊、呢、这个、那个、就是说、换句话说、对吧、是吧、嗯
2. **删除口语套话**：「废话不多说，直接进干货」「好，我们往下来看看」「啊，这个呢就也解释了」
3. **合并重复表达**：「反正反正」→「反正」、「一个一个问题」→「一个问题」
4. **修复破碎句式**：将说一半换方向的句子重组为完整句

### 第三步：修正转录错误

1. **专有名词大小写**：kevin → Kevin、eps → EPS、i p o → IPO、q e → QE
2. **同音错字**：正侧底 → 政策底、映映照回 → 映照回
3. **语义断裂修复**：根据上下文重建被语音识别打乱的句子
4. **数字规范化**：二五年 → 2025 年、一四年 → 2014 年、九二四 → 924

### 第四步：口语转书面语

将口语表达转为书面表达，同时保留作者的个人风格和分析语气。关键转换：
- 「吹了一下自己」→「先写了一句」
- 「人话就是」→「说白了就是」
- 「别大仓位干进去」→「别大仓位进场」
- 「你如果只看它这一段的话」→「如果只看这部分描述」
- 「那样子看到这里」→ 删除或替换为简洁过渡

### 第五步：组装输出

按以下结构组装最终文章：

```
# {文章标题}

### {章节标题1}
{整理后的正文段落}

### {章节标题2}
{整理后的正文段落}

...
```

格式要求：
- 段落间空一行
- 不同论点分段写
- 关键判断用 **加粗** 标注
- 保留原文中的比喻、案例和推理链
- 表格保持原样（如有）

### 第六步：质量自检

逐项检查以下清单（见下方「自检」section）。

## Output Format

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| 文章标题 | `# H1` | 从原文内容提取，概括全文主题 |
| 章节标题 | `### H3` | 4-8 个，按话题切分 |
| 正文段落 | 段落文本 | 书面语，段落间空一行 |
| 表格 | Markdown 表格 | 保留原文表格结构 |
| 加粗标记 | `**text**` | 关键判断和核心结论 |

## 自检

- [ ] 原文所有实质性观点是否全部保留？（不增不减）
- [ ] 是否还有残留的口语填充词？（呃、啊、呢、这个、对吧）
- [ ] 章节标题是否准确概括各段主题？（名词性短语、粒度一致）
- [ ] 专有名词大小写是否统一？（EPS、IPO、QE、Kevin）
- [ ] 年份是否统一为四位数字？（2025 年而非二五年）
- [ ] 段落布局是否符合规范？（段间空行、论点分段、关键判断加粗）
- [ ] 是否有语义不通的句子？（特别是语音识别错误修复处）
