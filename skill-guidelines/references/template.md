# 6 段标准模板

> 新建**自著** skill 时复制本模板替换占位符。第三方来源的说明书保持原格式（见 `SKILL.md`「边界」）。

---

```yaml
---
name: skill-name
description: >
  前置领词。写明何时该取用：一个 branch 一个触发条件，不列同义词清单。
  加一句排除条件，压掉与相邻 skill 的抢路由。
  不写正文已承载的身份描述，不写执行步骤。
---

- ...（说清要做什么，而非禁止什么）
- ...
- ...

## 边界
- 无法正向表述的硬护栏用陈述句钉死，并同时给出正向目标
- ...

# Relative files

| 场景 | 文件 | 内容 | 方式 |
|:---|:---|:---|:---|
| 始终 | SKILL.md | 核心流程 | — |
| 只有部分 branch 才碰的 | references/x.md | ... | 读取 |
| 结果必须精密且不许出错 | scripts/x.py | ... | 执行 |

| 优先级 | 来源 |
|:---|:---|
| 1 | 用户显式约定 |

| 3 | 环境（config、目录布局、`--help`）——查得到的留给环境 |

---

# 自检

- [ ] 每条都可核查且穷尽？
- [ ] ...
```

## 每段说明

| 段 | 作用 | 判据 |
|:---|:---|:---|
| YAML 指针 | agent 发现并到达它的唯一入口，每轮付费 | 一个 branch 一个触发条件；无同义清单；无正文已承载的身份；含排除条件 |
| Default stance | 定价值观 | 核心原则 + 边界各 ≥3 条；以陈述句说话 |
| Workflow | 定执行顺序 | 编号步骤，每步止于完成判据；不写成散文 |
| Output format | 固定输出结构 | 字段名 + 类型 |
| Relative files | 阶梯的下沉记录 | 每个文件标明读 vs 执行，以及哪个 branch 触发它 |
| Source hierarchy | 规则可追溯 | 含「环境」这一层；不确定标 `[待验证]` |
| 自检 | 兜底无法自动化的语义判断 | ≥3 条，可核查且穷尽；可自动化的已做成门禁而非自检条目 |
